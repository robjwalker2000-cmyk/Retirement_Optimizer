# Retirement_Optimizer

A self-contained retirement planning app for comparing savings, retirement timing,
future spending needs, fixed income, taxes, inflation, and expected investment
returns.

## Open the app

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python3 -m http.server 4173
```

Then visit:

```text
http://127.0.0.1:4173/
```

## Files

- `index.html` - app structure and controls
- `styles.css` - responsive interface styling
- `app.js` - projection model, optimizer insights, and chart rendering
